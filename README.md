\# Winsock Playground



Учебные реализации TCP эхо-сервера на Windows (Winsock2).



\## Содержание



| Папка | Модель | Клиентов одновременно |

|---|---|---|

| `01-echo-blocking` | блокирующие сокеты, один поток | 1 |



\## Сборка



Developer Command Prompt for VS, из папки `01-echo-blocking`:



&#x20;   cl /EHsc /std:c++17 server.cpp ws2\_32.lib

&#x20;   cl /EHsc /std:c++17 client.cpp ws2\_32.lib



\## Запуск



Сервер, затем клиент в отдельном окне. Адрес 127.0.0.1, порт 8080.



\## Известные ограничения



\- Один клиент за раз: остальные ждут в очереди `listen()`.

\- Нет фрейминга сообщений — данные длиннее буфера приходят частями.
